# 🛍️ ShopEase — Modern E-Commerce Website

A modern, responsive e-commerce shopping experience built with **HTML, CSS, and JavaScript**.

ShopEase allows users to explore products, search and filter categories, manage their shopping cart, save favorite items, and interact with product ratings and reviews.

## ✨ Features

- 🛒 **Shopping Cart** — Add products, update quantities, and remove items.
- ❤️ **Wishlist** — Save and manage favorite products.
- 🔍 **Product Search** — Quickly find products.
- 🗂️ **Category Filtering** — Browse products by category.
- ⭐ **Ratings & Reviews** — View product ratings and submit reviews.
- 💱 **Currency Switcher** — Switch between Nigerian Naira (NGN) and US Dollars (USD).
- 🌙 **Dark & Light Mode** — Switch between two themes.
- 📱 **Responsive Design** — Works across desktop, tablet, and mobile screens.
- 💾 **Local Storage** — Saves cart, wishlist, theme preferences, and reviews in the browser.
- ↕️ **Product Sorting** — Organize products using available sorting options.

## 🧰 Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## 🚀 Getting Started

To run ShopEase locally:

1. Clone this repository:

   ```bash
   git clone https://github.com/ChikaWebDev/ShopEase.git
   ```

2. Open the project folder.

3. Open `index.html` in your browser.

No additional installation is required.

## ⚠️ Important Notes

ShopEase is a front-end demonstration project.

- Checkout is a demonstration and does not process real payments.
- Product ratings and review counts are sample data.
- Reviews submitted by users are stored locally in their browser.
- Currency conversion uses a demonstration exchange rate, not a live financial rate.
